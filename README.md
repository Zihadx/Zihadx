## Engineering Principles

**01 — Clarity over cleverness**
Good systems should be understandable, not just functional.

**02 — Security is architecture**
It belongs in the design, not the final checklist.

**03 — UX is engineering**
A technically correct product can still be a bad product.

**04 — Ship, then refine**
The goal isn't theoretical perfection — it's useful software that gets better.
